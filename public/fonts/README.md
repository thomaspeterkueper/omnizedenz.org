# Lokale Fonts

Nach der Konvention von thomas-kueper.de werden Schriften lokal eingebunden,
nicht über Google Fonts. Benötigt werden nach Design-Fibel:

- **Crimson Text** (Lauftext) — Regular 400, Italic 400, SemiBold 600
- **Inter** (Überschriften, Symbole) — Regular 400, Medium 500, SemiBold 600

Als `.woff2` hier ablegen, dann die `@font-face`-Blöcke am Kopf von
`src/styles/global.css` einkommentieren.
